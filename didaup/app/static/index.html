Calcolo del carico didattico · TOT ORE EFFETTIVE

Le ore effettive del report originale non vengono riutilizzate. Per impostazione predefinita TOT ORE EFFETTIVE riprende TOT ORE PREVISTE; le regole possono applicare una percentuale, una quota fissa o il testo N.D. (non disponibile), senza modificare il file sorgente.

Regole per anno accademico
Una sola regola per riga: prevale la combinazione più specifica di tipologia, CdS e TAF. Regole ugualmente specifiche che intercettano la stessa riga sono un conflitto e bloccano la generazione. In assenza di una regola applicabile, le ore effettive coincidono con le ore previste. La modalità N.D. prevale sulle ore previste per le righe selezionate e non contribuisce al totale numerico. Se TOT ORE PREVISTE è vuoto e manca una regola N.D., il carico resta 0 con avviso; valori non numerici o negativi, conflitti e quote fisse eccedenti bloccano la generazione.

Regole di calcolo

Puoi selezionare più tipologie, CdS e TAF nella stessa regola. All'interno di ogni gruppo è sufficiente una corrispondenza; tra gruppi differenti devono corrispondere tutti i criteri impostati. Nessuna selezione significa «Tutti».

Azzeramento delle sole elaborazioni

Protetti e conservati: anni accademici, esclusioni delle annualità e motivazioni, mappature delle colonne, file Excel sorgenti, cronologia delle selezioni e account.

Questa funzione cancella soltanto eventuali file di lavoro rigenerabili prodotti dalle elaborazioni. Nella versione attuale non sono ancora previsti file generati da azzerare: se non ce ne sono, non viene cancellato nulla.

La conservazione nel database non sostituisce il backup Home Assistant. Eliminare l'app, cancellare /data o ripristinare un vecchio backup può comunque far perdere gli aggiornamenti successivi.
